1. pengertian java script dan kegunaannya. 
   bahasa pemrograman yang digunakan untuk membuat halaman website menjadi interaktif dan dinamis. JavaScript dapat digunakan untuk menampilkan pesan atau prompt, memvalidasi input pengguna, mengubah konten HTML, serta merespons tindakan pengguna seperti klik tombol.
2. pengertian jquery dan kegunaannya. 
   library JavaScript yang mempermudah penulisan kode untuk memanipulasi elemen HTML, mengatur CSS, menangani event, dan membuat efek pada halaman website. Dengan jQuery, beberapa tugas dapat dilakukan menggunakan kode yang lebih singkat dibandingkan JavaScript biasa.
3. perbedaan java script dan jquery. 
   java script merupakan bahasa pemrograman, sedangkan jQuery merupakan library yang dibuat menggunakan JavaScript. JavaScript dapat digunakan secara langsung di browser tanpa library tambahan, sedangkan jQuery perlu dimuat terlebih dahulu sebelum digunakan.
   javaScript biasa menggunakan metode seperti document.getElementById() untuk memilih elemen HTML, sedangkan jQuery menggunakan sintaks seperti $("#kotakWarna"). Keduanya dapat digunakan untuk membuat website interaktif, tetapi jQuery menyediakan sintaks yang lebih ringkas untuk manipulasi HTML, CSS, dan event.
